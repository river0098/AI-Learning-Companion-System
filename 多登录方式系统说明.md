## 🏗️ 架构设计

### 数据库模型

```
┌──────────┐
│   User   │ (主用户表)
└────┬─────┘
     │
     ├─────► AuthAccount (1:N) - 多种登录凭证
     ├─────► RefreshToken (1:N) - 刷新令牌
     └─────► LoginHistory (1:N) - 登录历史
```

#### User表（主用户）
```python
- id: 主键
- uuid: 全局唯一标识
- nickname: 昵称
- avatar: 头像
- user_type: 用户类型（student/parent/teacher）
- membership_type: 会员类型（free/vip）
- is_active: 是否激活
- is_verified: 是否已验证
```

#### AuthAccount表（认证凭证）
```python
- id: 主键
- user_id: 关联用户ID
- auth_type: 认证类型
  * wechat_h5: 微信H5
  * wechat_mini: 微信小程序
  * phone: 手机号
  * email: 邮箱
  * apple: Apple ID
  * google: Google账号
- auth_identifier: 认证标识（openid/unionid/phone/email）
- credential_data: 凭证数据（JSON）
- password_hash: 密码哈希（仅邮箱）
- is_verified: 是否已验证
```

#### RefreshToken表（刷新令牌）
```python
- id: 主键
- user_id: 关联用户ID
- token: 令牌字符串
- device_id: 设备ID
- ip_address: IP地址
- expires_at: 过期时间
- is_revoked: 是否已撤销
```

## 📡 FastAPI集成示例

```python
from fastapi import FastAPI, HTTPException, Depends, Header
from services.auth_service import (
    login_with_phone,
    login_with_email,
    login_with_wechat_h5,
    send_sms_code,
    decode_access_token
)

app = FastAPI()

# 认证依赖
def get_current_user(authorization: str = Header(None)):
    if not authorization:
        raise HTTPException(401, "未授权")

    try:
        token = authorization.replace("Bearer ", "")
        payload = decode_access_token(token)
        return payload
    except:
        raise HTTPException(401, "Token无效")

# 发送验证码
@app.post("/api/auth/sms/send")
async def send_sms(phone: str, purpose: str):
    result = send_sms_code(phone, purpose)
    return result

# 手机号登录
@app.post("/api/auth/phone/login")
async def phone_login(phone: str, code: str):
    result = login_with_phone(phone, code)
    return result

# 邮箱登录
@app.post("/api/auth/email/login")
async def email_login(email: str, password: str):
    result = login_with_email(email, password)
    return result

# 微信H5登录
@app.post("/api/auth/wechat/h5")
async def wechat_h5_login(code: str):
    result = login_with_wechat_h5(code)
    return result

# 受保护的路由
@app.get("/api/user/profile")
async def get_profile(current_user = Depends(get_current_user)):
    return {"user_id": current_user["user_id"]}
```

## 🎨 前端集成示例

### React/Vue示例
```javascript
// API客户端
class AuthAPI {
    constructor() {
        this.baseURL = 'https://api.example.com';
        this.accessToken = localStorage.getItem('access_token');
        this.refreshToken = localStorage.getItem('refresh_token');
    }

    // 发送验证码
    async sendSMS(phone, purpose = 'login') {
        const response = await fetch(`${this.baseURL}/auth/sms/send`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ phone, purpose })
        });
        return response.json();
    }

    // 手机号登录
    async loginWithPhone(phone, code) {
        const response = await fetch(`${this.baseURL}/auth/phone/login`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ phone, code })
        });

        const data = await response.json();

        if (data.success) {
            this.saveTokens(data.tokens);
        }

        return data;
    }

    // 保存Token
    saveTokens(tokens) {
        localStorage.setItem('access_token', tokens.access_token);
        localStorage.setItem('refresh_token', tokens.refresh_token);
        this.accessToken = tokens.access_token;
        this.refreshToken = tokens.refresh_token;
    }

    // 刷新Token
    async refreshAccessToken() {
        const response = await fetch(`${this.baseURL}/auth/refresh`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                refresh_token: this.refreshToken
            })
        });

        const data = await response.json();

        if (data.access_token) {
            localStorage.setItem('access_token', data.access_token);
            this.accessToken = data.access_token;
        }

        return data;
    }

    // 发送认证请求
    async authenticatedRequest(url, options = {}) {
        const headers = {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${this.accessToken}`,
            ...options.headers
        };

        let response = await fetch(url, { ...options, headers });

        // 如果Token过期，尝试刷新
        if (response.status === 401) {
            await this.refreshAccessToken();

            // 重试请求
            headers.Authorization = `Bearer ${this.accessToken}`;
            response = await fetch(url, { ...options, headers });
        }

        return response.json();
    }
}

// 使用
const auth = new AuthAPI();

// 登录
async function login() {
    await auth.sendSMS('13800138000');
    const code = prompt('请输入验证码');
    const result = await auth.loginWithPhone('13800138000', code);
    console.log('登录成功', result.user);
}
```

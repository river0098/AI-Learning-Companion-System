## 🚀 最快启动（3步）

### 方法1: 使用启动脚本（推荐）⭐

**Windows用户**:
```
双击: START.bat
```

**Linux/Mac用户**:
```bash
bash START.sh
```

### 方法2: 手动启动

```bash
# 1. 安装依赖（只需3个包，30秒）
pip3 install fastapi "uvicorn[standard]" pydantic

# 2. 启动服务器
cd backend/src
python3 api_server_simple.py

# 3. 打开浏览器
访问: http://localhost:8000
```

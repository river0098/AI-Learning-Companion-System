本文档详细说明了AI陪伴学习系统多登录方式的安全增强实现，包括：
- ✅ Redis集成的验证码和限频系统
- ✅ IP和设备级别的安全控制
- ✅ 账号冲突检测和合并机制
- ✅ 异常登录检测和告警
- ✅ Token黑名单和强制登出
- ✅ CAPTCHA集成支持

## 核心功能实现

### 1. Redis服务 (`redis_service.py`)

#### 1.1 验证码管理

**存储结构**：
```python
key: "sms:code:{purpose}:{phone_number}"
value: {
    "code": "123456",
    "created_at": "2025-11-03T10:00:00",
    "attempts": 0  # 失败次数
}
ttl: 300秒 (5分钟)
```

**核心方法**：
```python
# 保存验证码
redis_service.save_sms_code(phone_number, code, purpose='login', ttl=300)

# 验证验证码
success, error = redis_service.verify_sms_code(phone_number, code, purpose='login')

# 验证失败5次后自动锁定30分钟
```

#### 1.2 频率限制

**三级限频机制**：

1. **手机号级别**：
   - 1分钟内最多1条
   - 1小时内最多5条
   - 1天内最多10条

2. **IP级别**：
   - 1分钟内最多3次请求
   - 1小时内最多10次请求

3. **用户级别**：
   - 登录失败5次锁定30分钟

**实现代码**：
```python
# 检查短信频率
allowed, error = redis_service.check_sms_rate_limit(phone_number)

# 检查IP频率
allowed, error = redis_service.check_ip_rate_limit(ip_address, 'sms')

# 锁定手机号
redis_service.lock_phone(phone_number, 'login', duration=1800)
```

#### 1.3 Token黑名单

**用途**：
- 用户登出时将Refresh Token加入黑名单
- 强制登出所有设备
- 检测被盗用的Token

**实现**：
```python
# 加入黑名单
redis_service.add_token_to_blacklist(token, expires_in=30*86400)

# 检查黑名单
is_blacklisted = redis_service.is_token_blacklisted(token)
```

#### 1.4 异常登录检测

**检测维度**：
1. **IP地址变化**：1小时内3个不同IP
2. **地理位置突变**：10分钟内从A地到B地
3. **设备异常**：未受信任的设备

**实现**：
```python
# 记录登录
redis_service.record_login(user_id, ip, location, device_id)

# 检测异常
is_anomaly, reason = redis_service.check_login_anomaly(user_id, current_ip, location)
```

#### 1.5 CAPTCHA支持

**流程**：
```
1. 前端检测到需要CAPTCHA（IP请求过多）
2. 展示图形验证码/滑块验证
3. 用户完成验证，获得captcha_token
4. 后端验证captcha_token，通过后允许发送短信
```

**实现**：
```python
# 保存CAPTCHA结果
redis_service.save_captcha_token(token, valid=True, ttl=300)

# 验证CAPTCHA
is_valid = redis_service.verify_captcha_token(token)
```

### 2. 增强认证服务 (`auth_service_enhanced.py`)

#### 2.1 发送短信验证码（完整流程）

```python
def send_sms_code(
    phone_number: str,
    purpose: str = "login",
    ip_address: str = None,
    captcha_token: str = None
) -> Dict:
    """
    完整的短信发送流程
    """
    # 1. 验证手机号格式
    if not _validate_phone_number(phone_number):
        return {"success": False, "error": "手机号格式不正确"}

    # 2. IP频率检查（如果超限，要求CAPTCHA）
    if ip_address:
        ip_allowed, ip_error = redis_service.check_ip_rate_limit(ip_address, 'sms')
        if not ip_allowed:
            if not captcha_token or not redis_service.verify_captcha_token(captcha_token):
                return {
                    "success": False,
                    "error": ip_error,
                    "require_captcha": True  # 告诉前端需要CAPTCHA
                }

    # 3. 手机号频率检查
    phone_allowed, phone_error = redis_service.check_sms_rate_limit(phone_number)
    if not phone_allowed:
        return {"success": False, "error": phone_error}

    # 4. 生成6位随机验证码
    code = _generate_sms_code(length=6)

    # 5. 保存到Redis（5分钟TTL）
    redis_service.save_sms_code(phone_number, code, purpose, ttl=300)

    # 6. 调用短信服务商API
    sms_sent = _send_sms_via_provider(phone_number, code, purpose)

    if sms_sent:
        result = {"success": True, "message": "验证码已发送"}
        # 测试环境返回验证码（生产环境删除）
        if _is_test_mode():
            result["code"] = code
        return result
    else:
        return {"success": False, "error": "短信发送失败"}
```

**调用示例**：
```python
# API endpoint
@app.post("/api/auth/sms/send")
async def send_sms(request: PhoneSMSRequest, req: Request):

        purpose=request.purpose,
        ip_address=ip_address,

    )
```

#### 2.2 手机号登录（增强版）

```python
def login_with_phone_enhanced(
    phone_number: str,
    code: str,
    device_id: str = None,
    ip_address: str = None,
    user_agent: str = None,
    location: str = None
) -> Dict:
    """
    完整的登录流程，包含异常检测
    """
    # 1. 验证验证码（自动处理失败次数和锁定）
    success, error = redis_service.verify_sms_code(phone_number, code, 'login')
    if not success:
        return {"success": False, "error": error}

    # 2. 查找或创建用户
    auth_account = auth_db.get_auth_account('phone', phone_number)

    if auth_account:
        user = auth_db.get_user_by_id(auth_account.user_id)
        is_new_user = False
    else:
        # 首次登录，自动注册
        user = auth_db.create_user(nickname=f"用户{phone_number[-4:]}")
        auth_account = auth_db.create_auth_account(
            user_id=user.id,
            auth_type='phone',
            auth_identifier=phone_number,
            is_verified=True
        )
        is_new_user = True

    # 3. 异常登录检测
    warning = None
    if not is_new_user:
        is_anomaly, reason = redis_service.check_login_anomaly(
            user.id, ip_address, location
        )
        if is_anomaly:
            warning = reason
            # 发送异常登录通知
            _send_anomaly_notification(user.id, phone_number, reason)

    # 4. 记录登录信息
    redis_service.record_login(user.id, ip_address, location, device_id)
    auth_db.record_login(user.id, 'phone', ip_address, user_agent, device_id)

    # 5. 保存设备指纹
    if device_id:
        redis_service.save_device_info(user.id, device_id, {
            'user_agent': user_agent,
            'ip': ip_address,
            'first_seen': datetime.now().isoformat()
        })

    # 6. 生成Token对
    tokens = create_token_pair(user, device_id, ip_address, user_agent)

    return {
        "success": True,
        "user": {...},
        "tokens": tokens,
        "is_new_user": is_new_user,
        "warning": warning  # 异常登录警告
    }
```

#### 2.3 账号绑定与冲突处理

**场景1：无冲突绑定**
```python
# 用户A（微信登录）想绑定手机号13800138000
# 该手机号未被使用 → 直接绑定成功
```

**场景2：冲突检测**
```python
# 用户A（微信登录）想绑定手机号13800138000
# 发现该手机号已被用户B绑定 → 返回冲突信息和合并token
```

**场景3：账号合并**
```python

# 将用户A的所有认证方式转移到用户B
# 用户A标记为已合并状态（不删除，保留审计）
```

**实现代码**：
```python
def bind_phone_enhanced(user_id: int, phone_number: str, code: str) -> Dict:
    # 1. 验证验证码
    success, error = redis_service.verify_sms_code(phone_number, code, 'bind')
    if not success:
        return {"success": False, "error": error}

    # 2. 检查当前用户是否已绑定手机号
    if auth_db.get_auth_account_by_user('phone', user_id):
        return {"success": False, "error": "您已绑定手机号"}

    # 3. 检查冲突
    existing_account = auth_db.get_auth_account('phone', phone_number)

    if existing_account and existing_account.user_id != user_id:
        # 生成合并token
        merge_token = _generate_merge_token(
            from_user_id=user_id,
            to_user_id=existing_account.user_id,
            auth_type='phone',
            identifier=phone_number
        )

        return {
            "success": False,
            "conflict": True,
            "error": "该手机号已被其他账号使用",
            "merge_token": merge_token,
            "message": "检测到您可能拥有多个账号，是否合并？"
        }

    # 4. 无冲突，直接绑定
    auth_db.create_auth_account(
        user_id=user_id,
        auth_type='phone',
        auth_identifier=phone_number,
        is_verified=True
    )

    return {"success": True, "message": "绑定成功"}


def merge_accounts(merge_token: str, confirmation_code: str = None) -> Dict:
    """
    执行账号合并
    """
    # 1. 验证merge_token（从Redis获取）
    merge_data = _get_merge_data(merge_token)
    if not merge_data:
        return {"success": False, "error": "合并请求已过期"}

    # 2. 可选：再次验证短信（增强安全性）

            confirmation_code,
            'merge'

            account.user_id = to_user_id
        else:
            # 已存在则删除from_user的
            auth_db.session.delete(account)

    # 4. 转移refresh_tokens
    # 5. 记录合并日志
    # 6. 标记from_user为已合并

    auth_db.session.commit()

    return {"success": True, "message": "账号合并成功"}
```

#### 2.4 Token管理增强

**Access Token（短期）**：
- 有效期：1小时
- 格式：JWT
- 存储：前端LocalStorage或Cookie
- 用途：API请求认证

**Refresh Token（长期）**：
- 有效期：30天
- 格式：随机字符串（URL-safe base64）
- 存储：数据库 + Redis黑名单
- 用途：刷新Access Token

**Token刷新流程**：
```python
def refresh_access_token_enhanced(refresh_token: str, ip_address: str) -> Dict:
    # 1. 检查黑名单
    if redis_service.is_token_blacklisted(refresh_token):
        return {"success": False, "error": "Token已失效"}

    # 2. 从数据库验证
    token_record = auth_db.get_refresh_token(refresh_token)
    if not token_record or token_record.is_revoked:
        return {"success": False, "error": "Invalid token"}

    # 3. 检查过期
    if datetime.now() > token_record.expires_at:
        return {"success": False, "error": "Token已过期"}

    # 4. 生成新的Access Token
    user = auth_db.get_user_by_id(token_record.user_id)
    access_token = _create_access_token(user)

    # 5. 更新last_used时间
    token_record.last_used = datetime.now()
    auth_db.session.commit()

    return {
        "success": True,
        "access_token": access_token,
        "expires_in": 3600
    }
```

**强制登出所有设备**：
```python
def logout_all_devices(user_id: int):
    # 1. 撤销数据库中所有refresh tokens
    tokens = auth_db.get_user_refresh_tokens(user_id)
    for token in tokens:
        token.is_revoked = True
        token.revoked_at = datetime.now()

        # 2. 加入Redis黑名单
        redis_service.add_token_to_blacklist(token.token, 30*86400)

    auth_db.session.commit()
    return {"success": True, "message": f"已登出{len(tokens)}个设备"}
```

### 2. 设备指纹采集

```javascript
function getDeviceFingerprint() {
    // 采集设备信息
    const deviceInfo = {
        userAgent: navigator.userAgent,
        language: navigator.language,
        platform: navigator.platform,
        screenResolution: `${screen.width}x${screen.height}`,
        timezone: Intl.DateTimeFormat().resolvedOptions().timeZone,
        plugins: Array.from(navigator.plugins).map(p => p.name),
    };

    // 生成指纹哈希
    const fingerprint = hashObject(deviceInfo);

    // 保存到localStorage
    localStorage.setItem('device_id', fingerprint);

    return fingerprint;
}

function hashObject(obj) {
    const str = JSON.stringify(obj);
    let hash = 0;
    for (let i = 0; i < str.length; i++) {
        const char = str.charCodeAt(i);
        hash = ((hash << 5) - hash) + char;
        hash = hash & hash;
    }
    return Math.abs(hash).toString(36);
}
```

### 5. Token自动刷新

```javascript
// 检查Token是否即将过期
function isTokenExpiringSoon(token) {
    try {
        const payload = JSON.parse(atob(token.split('.')[1]));
        const expiresAt = payload.exp * 1000;
        const now = Date.now();
        // 如果5分钟内过期，则刷新
        return expiresAt - now < 5 * 60 * 1000;
    } catch {
        return true;
    }
}

// 自动刷新Token
async function autoRefreshToken() {
    const accessToken = localStorage.getItem('access_token');
    const refreshToken = localStorage.getItem('refresh_token');

    if (!accessToken || !refreshToken) {
        return;
    }

    if (isTokenExpiringSoon(accessToken)) {
        try {
            const response = await fetch('/api/auth/token/refresh', {
                method: 'POST',
                headers: {'Content-Type': 'application/json'},
                body: JSON.stringify({ refresh_token: refreshToken })
            });

            const result = await response.json();

            if (result.success) {
                localStorage.setItem('access_token', result.access_token);
                console.log('✅ Token已自动刷新');
            } else {
                // Refresh token也失效了，跳转登录
                console.log('⚠️ Token刷新失败，请重新登录');
                localStorage.clear();
                window.location.href = '/login';
            }
        } catch (error) {
            console.error('Token刷新失败:', error);
        }
    }
}

// 每分钟检查一次
setInterval(autoRefreshToken, 60000);

// 发送请求前也检查
async function fetchWithAuth(url, options = {}) {
    await autoRefreshToken();

    const token = localStorage.getItem('access_token');
    options.headers = {
        ...options.headers,
        'Authorization': `Bearer ${token}`
    };

    return fetch(url, options);
}
```
